# テ。-天球の運動について-

長編小説企画の管理ディレクトリ。

## 現在の応募用タイトル

『それでも地球は回ってる？』

## 作品の核

現代の高校生が「地動説が正しい」という答えを最初から知った状態で、観測・計算・プログラム・科学史を使って、その答えへ自力で辿り直す科学青春小説。

主人公・深草早希は、好奇心が強く未知にはすぐ飛びつく一方、面倒くさがりで、理解したと思うのが早い。最初は昔の天文学者を「間違った説を信じた人」と軽く見ているが、プトレマイオス、コペルニクス、ティコ、ケプラー、ブラッドリー、ベッセルへと検証を進めるうちに、「正解を知っていること」と「観測からどこまで言えるか」は別だと知る。

最終テーマは「巨人の肩に乗る」。

早希は最後に、歴史上の科学者たちだけでなく、自分たちの研究を支えていた吉田せつなもまた、自分を高い場所へ持ち上げてくれた一人だったと気づく。
